# LiDAR_Simulation
LiDAR (Light Detection and Ranging) is used for several purposes, such as calculating an object's position and velocity using laser pulses or generating 3D images of terrain. In our case, we will focus on the former purpose. In this project, we have simulated LiDAR with an Extended Kalman Filter using Python.
